Safe Windows setup checklist

Most install failures are skipped Windows settings. Follow this checklist before you blame the client.

Why setup fails before the game even opens

Most "it does not work" tickets are Windows options, not mysterious bugs. DOTA2 Cheats expects HVCI, Core Isolation, TPM, and Secure Boot enabled, with Cloud DMA for full functionality. Read Cloud DMA explained first, then follow this checklist.

Checklist before you buy or install

  1. Confirm Windows 10 or Windows 11 64-bit.
  2. Enable TPM and Secure Boot in BIOS/UEFI as required.
  3. Enable HVCI / Core Isolation in Windows Security.
  4. Restart and verify the settings stuck.
  5. Only then install the client from your dashboard credentials.

Exact answers live on the FAQs page. Support is on Discord.

After purchase

Checkout is on zadeyo. Credentials arrive instantly. Download from the dashboard, run the installer, follow the included steps. Do not skip the Cloud DMA portion if you want full ESP and map tools.

Performance expectations

The software is built for low CPU and memory impact. Cloud DMA offloads work so FPS stays stable. If performance tanks, re-check background overlays and verify you followed the requirements on the homepage.

License notes

One license is tied to one machine. Hardware changes may need a support transfer. Refunds are case-by-case for technical issues reported quickly. Details: FAQs.
